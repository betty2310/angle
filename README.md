# GNSS spoofing detection from carrier-phase DD angle of arrival

Research workspace for the paper:

> **GNSS Spoofing Detection by Estimating Angle of Arrival based on Carrier Phase Double
> Difference Measurements**, Hiep Hoang Van and Thuan Nguyen Dinh.

Two closely spaced u-blox receivers log raw carrier phase. With the antenna baseline set to one
L1 wavelength, the fractional part of the carrier-phase double difference (DD) depends on
`cos(alpha_i) - cos(alpha_r)`, where `alpha` is a satellite's angle of arrival (AoA) relative
to the baseline and `r` is the reference satellite. The code estimates each satellite's
**DD-method AoA** and compares it with the **ephemeris-based AoA** computed from broadcast
ephemeris. When several PRNs' DD-method AoAs collapse to one common direction while their
ephemeris-based AoAs stay satellite-specific, those PRNs come from a single source. That
disagreement is the spoofing signature.

This repository holds detection and analysis code only. The test signals were generated by the
authors with their fork of [gps-sdr-sim](https://github.com/betty2310/gps-sdr-sim) and fed to
their own receivers over a conducted (cabled) RF path or inside a shielded enclosure.

Related repositories:

- [gnss-aoa-dd](https://github.com/betty2310/gnss-aoa-dd): the trimmed, reproducible release
  of the paper flow with the `sp-partial-28-09` and authentic datasets included.
- [gps-sdr-sim](https://github.com/betty2310/gps-sdr-sim): the signal generator used to make
  the test signals.

This repository is the full working tree behind both: every capture, the exploratory
classifiers, and the scripts used for the manuscript figures.

## Run

Run everything from the repository root.

```bash
uv run jupyter notebook AOA_Paper.ipynb            # 1. run the experiment
uv run jupyter notebook AOA_Export_Figures.ipynb   # 2. export figures for that run
```

Before a new capture goes through `AOA_Paper.ipynb`, check the data and the rig:

```bash
uv run python scripts/probe_dataset.py dataset/<capture> --spoof <PRNs>
uv run python scripts/calibrate_baseline_azimuth.py dataset/<capture> --spoof <PRNs>
```

### Branch selection

The DD gives each satellite several candidate AoAs, one per integer branch `m`. Every result
reports how the branch was picked (`chosen_by`):

- `data`: the measurements alone picked the branch.
- `prior`: the branches fit equally well and `prior_aoa_deg` picked one.
- `unresolved`: the branches fit equally well and no prior was given.

The alternative branch is always reported next to the chosen one. Epochs without valid carrier
phase or a position fix are kept as gaps and never interpolated.
